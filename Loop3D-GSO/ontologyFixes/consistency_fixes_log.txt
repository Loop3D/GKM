## 1. Event class - Removed hasPart restriction
--------------------------------------------------------------------------------
ISSUE: Event had conflicting restrictions:
  - hasConstituent some Process
  - hasPart only Event
  - Event disjointWith Process

Since hasConstituent -> hasPersistentPart -> hasEssentialPart -> hasPart,
Event must have Process as part, but can only have Event as parts.

REMOVED:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom gsoc:Event ;
      owl:onProperty gsoc:hasPart ;
    ] ;

--------------------------------------------------------------------------------

## 2. Quality_Value class - Removed disjointWith restriction
--------------------------------------------------------------------------------
ISSUE: Quality_Value was disjoint with things having Particular parts, but
Range_Value (subclass) needs hasEndValue/hasStartValue which are subproperties
of hasPart, requiring Measure_Value or Named_Value (which are Particulars).

REMOVED:
  owl:disjointWith [
      rdf:type owl:Restriction ;
      owl:onProperty gsoc:hasPart ;
      owl:someValuesFrom gsoc:Particular ;
    ] .

--------------------------------------------------------------------------------

## 3. Inherant class - Removed disjointWith Relator
--------------------------------------------------------------------------------
ISSUE: Pattern_Feature subClassOf Inherant_Feature, which requires hasEssentialPart
only Inherant. But Pattern_Feature needs hasEssentialPart some Relator.
Relator was disjoint with Inherant.

REMOVED:
  owl:disjointWith gsoc:Relator .

--------------------------------------------------------------------------------

## 4. Time_Interval_Location class - Removed hasQuality restriction
--------------------------------------------------------------------------------
ISSUE: Time_Interval_Location had hasQuality some Duration.
Duration is a Temporal_Quality which requires isQualityOf exactly 1 Perdurant.
But Time_Interval_Location is an Endurant (via Quality hierarchy).
Endurant is disjoint with Perdurant.

REMOVED:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:onProperty gsoc:hasQuality ;
      owl:someValuesFrom gsoc:Duration ;
    ] ;

--------------------------------------------------------------------------------

## 24. Event_Feature class - Widened hasEssentialPart restriction
--------------------------------------------------------------------------------
ISSUE: Event has hasConstituent some Process, and through property chain
hasConstituent -> hasPersistentPart -> hasEssentialPart, Event has Process
as essential part. But Event_Feature had hasEssentialPart only Event.

CHANGED FROM:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom gsoc:Event ;
      owl:onProperty gsoc:hasEssentialPart ;
    ] ;

CHANGED TO:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom [
          rdf:type owl:Class ;
          owl:unionOf (
              gsoc:Event
              gsoc:Process
            ) ;
        ] ;
      owl:onProperty gsoc:hasEssentialPart ;
    ] ;

--------------------------------------------------------------------------------

## 25. Nonphysical_Quality class - Widened isQualityOf restriction
--------------------------------------------------------------------------------
ISSUE: Statistical_Calculation (a Perdurant via Event) had hasQuality some
Unit_Of_Measure. Unit_Of_Measure is Nonphysical_Quality. But Nonphysical_Quality
had isQualityOf only Nonphysical_Endurant. Through hasQuality inverse isQualityOf,
this forced Statistical_Calculation to be Nonphysical_Endurant (an Endurant),
conflicting with it being a Perdurant (Endurant disjointWith Perdurant).

CHANGED FROM:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom gsoc:Nonphysical_Endurant ;
      owl:onProperty gsoc:isQualityOf ;
    ] ;
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:onClass gsoc:Nonphysical_Endurant ;
      owl:onProperty gsoc:isQualityOf ;
      owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;
    ] ;

CHANGED TO:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom [
          rdf:type owl:Class ;
          owl:unionOf (
              gsoc:Nonphysical_Endurant
              gsoc:Perdurant
            ) ;
        ] ;
      owl:onProperty gsoc:isQualityOf ;
    ] ;
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:onClass [
          rdf:type owl:Class ;
          owl:unionOf (
              gsoc:Nonphysical_Endurant
              gsoc:Perdurant
            ) ;
        ] ;
      owl:onProperty gsoc:isQualityOf ;
      owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;
    ] ;

## 26. Perdurant class - Widened hasQuality restriction and removed nested restriction
--------------------------------------------------------------------------------
ISSUE: Perdurant had hasQuality only Temporal_Quality. But Statistical_Calculation
(a Perdurant) needed hasQuality some Unit_Of_Measure (a Nonphysical_Quality).
Nonphysical_Quality disjointWith Temporal_Quality caused conflict.

CHANGED FROM:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom gsoc:Temporal_Quality ;
      owl:onProperty gsoc:hasQuality ;
    ] ;
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:allValuesFrom [
          rdf:type owl:Restriction ;
          owl:allValuesFrom [
              rdf:type owl:Restriction ;
              owl:onClass gsoc:Temporal_Quality ;
              owl:onProperty gsoc:isStaticValueOf ;
              owl:qualifiedCardinality "1"^^xsd:nonNegativeInteger ;

CHANGED TO:

## 27. Statistical_Calculation class - Changed hasQuality to hasOutput
--------------------------------------------------------------------------------
ISSUE: Statistical_Calculation had hasQuality some Unit_Of_Measure.
This was semantically incorrect - a calculation should have a RESULT
(output) that is a Measure_Value, which then has Unit_Of_Measure as quality.
Also caused conflict because Unit_Of_Measure isQualityOf only Measure_Value.

CHANGED FROM:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:onProperty gsoc:hasQuality ;
      owl:someValuesFrom gsoc:Unit_Of_Measure ;
    ] ;

CHANGED TO:
  rdfs:subClassOf [
      rdf:type owl:Restriction ;
      owl:onProperty gsoc:hasOutput ;
      owl:someValuesFrom gsoc:Measure_Value ;
    ] ;

## 29. timeInclusion property - Removed SymmetricProperty declaration
--------------------------------------------------------------------------------
ISSUE: timeInclusion was declared as SymmetricProperty, but has timeIncludedBy
and timeIncludes as subproperties (which are inverses). This caused exponential
inference explosion when reasoning over ISChart with ~600 time intervals.

Semantically, timeInclusion being symmetric is redundant - the inverse
relationship is already captured by timeIncludedBy/timeIncludes being inverses.

REMOVED:
  rdf:type owl:SymmetricProperty ;

FROM:
  gsoc:timeInclusion
